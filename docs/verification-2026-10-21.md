## 独立审查与修复

路网和 GUI 分别经独立任务审查，最后进行了整体集成审查。发现并修复：

1. 可达与不可达结果混合时，大整数目标 ID 被 pandas 推断为浮点数，造成精度丢失。
2. GPKG 非空间属性表导致 GUI 读取几何时报错，并可能保留旧结果。
3. 统计值字段与目标 ID 字段相同时，数值转换覆盖业务 ID。现在明确要求选择独立统计字段。

以上均新增回归测试并通过复审。整体审查未发现新的阻塞问题；README 的可选依赖测试命令已按审查意见修正。

## 实现选择与边界

- 使用本地 Streamlit 与可选 NetworkX，不引入在线道路下载。输入道路应已有正确节点拓扑；不会自动把内部交叉切为路口。OSMnx 导入适配器留待后续。
- 逐目标反向 Dijkstra，流式更新最优结果，避免完整源目标矩阵。大量目标仍会增加计算时间；GUI 用行数和工作量预算限制试用范围。
- GUI 快照仅保存分析所需字段和几何，采用严格 JSON+WKB 保留 dtype/CRS，沿用 export_run 清单和哈希。重放需要安装相应包和依赖，ZIP 不包含 Python 解释器。
- 当前界面以表格预览和结果下载为主，不包含地图编辑、路径可视化或真实步行障碍判定。
- 按用户要求跳过真实北京数据及 QGIS 对照；未做浏览器上传验收、城市级性能测试和云端跨平台 CI。
- 代码保留在本地开发分支，未上传 GitHub。
