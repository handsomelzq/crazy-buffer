# 方法与科学边界

范围成员资格以原始几何到目标点的平面距离 `distance <= radius_m` 判断，包含边界。对公园面，内部点距离为零；外部点距离为到面边界的最短距离。它不是到公园中心或入口的距离。空间索引只筛选候选，最终仍作精确距离判定。

`make_buffers` 输出绘图和检查用的近似圆弧多边形，quad_segs 控制每四分之一圆的分段数。范围查询不依赖该近似边界，不能用图上多边形的细微差异否定距离判断。

每个目标业务 ID 计一次；多个源的重叠范围分别计算。n_matches 为几何匹配数，n_valid_values 为非空有效值数，mean_value 为有效值的算术平均，无面积权重或人口权重。不接受数值字符串、布尔值或无穷值；空值不计入均值。无匹配时 status=no_matches，匹配但全为空时 no_valid_values，两种情况均值均为空，不能填作零房价。

最近目标为投影平面欧氏距离。仅当计算出的距离严格相等时算并列，不使用近似容差。等距按 ID 的字符串表示排序选首个（整数 10 会排在 2 前面），tie_count 保留并列数量。不能推断步行时间、路网距离或真实站点入口可达性。

投影是否适合研究区由调用方负责；米制不等于无畸变。GCJ-02、BD-09 未实现转换；不能通过改 CRS 标签消除偏移。合成坐标附 EPSG:32650 仅供可重复计算，不是观测地理位置。

neighbors_within 会物化全部关系并默认限制一百万条；超限报错。iter_neighbor_batches 按源批次产生关系，单批仍可能很大；buffer_stats 分批聚合、不保留完整关系表，但目标索引和聚合状态仍占内存。当前未做大规模性能基准，不承诺常量内存。

本库计算空间描述统计，不解决样本选择偏差、挂牌价与成交价差别、空间自相关或因果识别。真实研究需记录时间、价格单位、测量位置及缺失处理。导出哈希便于核查材料一致性，不是授权、真实性或结论正确性的证明。

`facility_mix` 对每个研究源在缓冲半径内逐个目标点计数。密度是
`类别设施数 / 完整缓冲面面积 × 1,000,000`；研究源为面时缓冲面包含面外扩部分，
不是仅统计面内与缓冲区相交的部分。POI 计数是数据表中的观测数量，分类点的完整性、
去重和抽取偏差仍会直接影响变量。

类别多样性使用标准化 Shannon 熵：

`entropy = -Σ(p_k ln p_k) / ln(K)`。

其中 `p_k` 为当前研究范围内第 k 类设施或用地占全部正权重类别的比例，`K` 为当前范围内
非零类别数。只有一个非零类别时熵为 0；没有类别时为缺失，不能与功能单一等同。
标准化使不同研究范围可比较，但类别体系、`K` 和分类数据质量必须保持一致。

`land_use_mix` 的面积在米制投影中计算。同一类别中的重叠多边形先作并集，避免同一块地因
两个数据切片被重复相加。不同类别的重叠会令类别面积之和大于实际覆盖面积；库通过
`overlap_area_m2` 和运行报告提示冲突，不擅自决定哪一类正确。`share_<label>` 以完整分析
范围面积为分母，因此缺失类别数据表现为占比和覆盖率同时偏低；`entropy` 则以已分类覆盖
面积为分母，只解释“现有分类数据内部的混合程度”。土地利用混合度不能直接替代 POI
多样性，也没有默认判定功能混合“好坏”的规范阈值。

缓冲区圆滑使用 `quad_segs=32`，其面积与理想圆存在极小的多边形近似差异。面积与密度
应记录该实现参数；距离成员资格仍通过原始几何的精确平面距离判断。

估计路网距离的方法、拓扑、接入和不可达状态见 [路网说明](network.md)。逐目标反向 Dijkstra 的工作量随目标数、节点与道路数增加；GUI 额外限制 `目标数 × (源数 + 道路数) <= 2000000`，Python API 不施加这一试用预算。
