# 地图工作台验收

日期：2026-10-21。范围为本地 GUI 改造，不新增空间指标，也不执行真实北京数据或 QGIS 对照。

## 本次交付

- 左侧数据图层、中间地图、右侧分析参数；顶部切换三个已有工具。
- CARTO Positron 底图，OpenStreetMap / CARTO 署名，支持关闭底图。
- 点、线、面预览，图层显隐，属性表，自动视野，米制缓冲预览。
- 合成数据平移至北京附近，保留原相对位置和计算结果；明确标注虚构性质。
- 上传经纬度字段初选、UTM 投影建议；进阶参数折叠，计算和显示投影分离。
- 底图或显隐变化保留结果；计算参数和上传数据变化清除旧结果。

## 已验证

- `uv run --offline --locked --extra gui pytest -q -W error`：174 项通过，19.00 秒。
- wheel / sdist 构建成功，包含地图模块和 CSS，不包含项目缓存与虚拟环境。
- 浏览器确认浅色三栏布局、CARTO 底图、研究点、目标点和缓冲面正确显示。
- 浏览器关闭底图后，地图底层和署名控件消失，本地图形仍可显示；核对 Streamlit 1.66 前端逻辑，使用无底图标记阻止默认 CARTO 回填。
- 浏览器运行缓冲示例得到均值 10 和 30，显示结果及 CSV / ZIP 下载入口。
- 上传 CSV 的字段识别、投影建议和运行通过 AppTest；面缓冲、重投影、空几何、预览截断、输入不变通过地图单元测试。

## 审查修复

独立 agent 审查发现旧版 Streamlit 参数兼容性和关闭底图自动回填问题，均已处理。浏览器检查发现字典样式不受 Streamlit 支持，以及 pydeck 将像素单位字符串解析为表达式，已改为样式 URL 与显式字符串字面量并加回归测试。

## 边界

底图需网络，请求包含当前地图视野；分析文件不上传到地图服务。每层只预览前 2000 条并提示，计算不受这个预览上限影响。缓冲图形是圆弧离散预览，统计仍使用精确距离。暂未新增结果分级着色、最短路径绘图或地图编辑。未进行真实数据验收、城市级性能测试、跨平台云端 CI，也未发布 GitHub。
