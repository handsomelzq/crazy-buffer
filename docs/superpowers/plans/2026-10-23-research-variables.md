# 科研变量任务扩展计划

## 目标

在现有 Python API 与本地 GUI 中增加三类高频科研变量，不引入新的运行时依赖：

1. 分类设施数量、密度与类别多样性；
2. 用地面积、占比、覆盖率与类别多样性；
3. GUI 的“周边设施”和“用地构成”入口。

## 实施范围

- `facility_mix`：研究源点/面加分类目标点，按精确平面距离筛选，输出总数量、
  分类数量、每平方公里密度和标准化 Shannon 熵。
- `land_use_mix`：研究源自身范围或外扩缓冲面与分类用地面相交，输出分类面积、
  占比、覆盖率、重叠量和标准化 Shannon 熵。
- GUI 复用原有三栏布局、CARTO Positron 底图、图层显隐、缓冲预览、CSV 和 ZIP
  重放，不增加云端计算或隐式数据下载。
- 增加合成示例、API/方法/GUI 文档与回归测试。

## 固定方法口径

- 设施密度分母是完整缓冲面面积，包括外扩至行政边界以外的部分。
- 用地占比分母是完整分析范围面积；标准化熵分母是已分类覆盖面积。
- 同类用地先作并集；不同类别重叠通过 `overlap_area_m2` 和运行报告显式提示。
- 单一类别熵为 0；没有数据时为缺失，不填作 0。
- 缓冲面采用 `quad_segs=32`，距离成员资格使用原始几何的精确平面距离。

## 验证

- 完整测试：191 项通过，警告按错误处理。
- 新任务、旧任务、GUI 服务和仓库外 ZIP 重放均有回归测试。
- wheel/sdist 构建成功，包含新模块且不包含缓存、虚拟环境或字节码。
- 浏览器检查两个新入口、三栏布局、底图、用地图层、缓冲预览、结果和下载入口。
