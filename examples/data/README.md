# 合成数据说明

生成入口为 ../scripts/sample_data.py；没有下载或嵌入真实北京数据。坐标为合成平面米，附 EPSG:32650 作为米制计算声明；这些低值坐标不代表真实研究区。ID 为业务字符串，001 的前导零有意义。

公园 P1 为 (0,0) 到 (10,10) 的正方形，P2 为 (100,100) 到 (110,110)。住房 H1(5,5)、H2(15,5)、H3(30,5)，price 分别为 10000、30000、90000 元/平方米。公园范围距离半径 5 米，P1 匹配 H1/H2，均价 20000，P2 无匹配。

最近站示例起点 001(0,0)、002(3,4)，站点 B(3,4)、A(-3,4)。001 到 A/B 均为 5 米，按字符串 ID 选 A，tie_count=2；002 到 B 为 0 米。

周边设施示例有两个研究对象，坐标 (0,0) 与 (100,0)，半径 10 米。第一个范围中有两类 3 个设施；第二个范围中只有 1 个教育设施。结果用于演示分类计数、密度及混合度。

用地构成示例有两个 10×10 米规则研究单元。第一个单元为 60% 居住与 20% 绿地，剩余 20% 无分类数据；第二个单元为 80% 居住与 20% 商业。结果用于演示面积、占比、覆盖率和混合度。
